# Лабораторная работа 2

## Требования
- Python 3.x
- SQLite 3.x

## Запуск
1. Установить Python и SQLite.
2. Запустить `db_init.bat`.
3. Будет создана база данных `movies_rating.db` с таблицами movies, ratings, tags, users.

## Файлы
- `make_db_init.py` — генерирует SQL-скрипт из CSV-файлов
- `db_init.bat` — запускает генерацию и создание базы данных
- `db_init.sql` — сгенерированный SQL-скрипт
- `movies_rating.db` — итоговая база данных
