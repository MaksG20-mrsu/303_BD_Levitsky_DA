# Задание 1. Подготовка данных

## Структура файлов данных

В папке Task01 находятся следующие файлы:

* **movies.csv** — информация о фильмах (название, жанры и т.д.)
* **ratings.csv** — оценки пользователей (userId, movieId, rating, timestamp)
* **tags.csv** — теги, присвоенные пользователями фильмам
* **users.txt** — информация о пользователях
* **genres.txt** — список жанров
* **occupation.txt** — список профессий пользователей
* **ratings_count.txt** — минимальный и максимальный ID пользователя и количество оценок с этими ID
* **sqlite.txt** — версия SQLite и доступные режимы вывода
